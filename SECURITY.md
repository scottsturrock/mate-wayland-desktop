# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it
privately, either way:

- e-mail <security@mate-wayland.org>, or
- use "Report a vulnerability" on the Security tab of this repository.

Include what is affected, how to reproduce it and, if you know it, the name
of the ISO file you installed from.

## What this covers

- The project's own files: the session package, the build system, the
  installer settings and the default configuration of the ISO.
- The MATE packages the project rebuilds, where the problem comes from the
  project's changes.

Vulnerabilities in programs taken unchanged from Ubuntu, Mozilla, MATE or
labwc are best reported to those projects; tell us as well if the default
configuration of this system makes them worse.

## Updates

The base system and Firefox receive security updates from Ubuntu's and
Mozilla's package archives in the usual way.
